# Herdr 본체 패치 보관

기준 소스는 Herdr `v0.9.5`, commit `2ecf19a`다. 현재 설치한 통합 후보를 다른 컴퓨터에서도 재현할 수 있도록 두 변경을 각각 보존한다.

| 파일 | 적용 범위 |
| --- | --- |
| `status-height.patch` | `src/layout.rs`: 분할 비율을 0.01~0.99로 허용하고 정규화 경로를 통일해 하단 외곽 5행을 지원한다. |
| `copy-dedent.patch` | 기존 Shift+Y 복사 동작의 5개 파일: 선택한 줄의 공통 들여쓰기 제거와 관련 키·상태 처리. 높이 변경은 포함하지 않는다. |

패치는 기준 소스의 diff 원문이며 두 파일의 수정 대상은 겹치지 않는다. 다른 변경이 있는 checkout에서는 기존 작업을 보존하고 적용 가능 여부부터 확인한다. 다른 Herdr 버전에 그대로 적용된다고 보장하지 않는다.

Unified diff의 빈 context 행은 단일 공백을 포함한다. 이 원문을 변조하지 않도록 이 디렉터리의 `.gitattributes`는 `.patch` 파일의 줄 끝 공백 판정만 형식에 맞게 지정한다. 제품 소스의 공백 검사에는 영향을 주지 않는다.

일반 dotfiles 설치는 이 패치를 Herdr 본체에 적용하거나 본체를 재빌드·설치하지 않는다. 하단 Rust 실행기 빌드와 Herdr 본체 배포는 별개다. 개인컴에서도 본체 패치 적용·빌드와 실행 중 프로세스를 보존하는 배포 절차가 별도로 필요하다. 자동 다운로드나 별도 빌드 인프라는 추가하지 않는다.
