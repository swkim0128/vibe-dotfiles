## 💼 업무컴

### 최신화 이후 TUI 작업본 복원 충돌 정리

- 최신 통합 작업 큐와 하단 TUI 높이 설정을 유지했다. 보관본의 Slack 멘션 유무 표시와 빠른 실행 버튼의 왼쪽 배치를 현재 화면 구조에 반영했다.
- 이전 터미널 실행기 연결은 복구 사본에 보존했다. TUI 바이너리 재빌드와 실행 중 화면 반영은 수행하지 않았다.

### TUI 큐 작업 구분 표시

- 연결된 PARA 노트 경로 또는 명시적인 큐 키를 기준으로 작업 제목에 `[개인]`·`[회사]`를 붙였다. 구분 근거가 없는 요청은 `[미분류]`로 표시한다.
- 업무·개인 세션의 TUI에서 새 라벨과 기존 공통 단계 흐름을 확인했다.

### 기본 큐에 서브 실행 요약 표시

- 인계받은 `main.rs`·`actions.rs` 변경으로 기본 큐 헤더에 서브 실행 요약을 표시했다. personal의 기존 실행 탭에서 `mise exec -- cargo build --locked --release`와 `python3 -B tests/test_herdr_display.py`를 실행해 빌드와 검사 9개가 통과했다.
- personal 첫 탭의 하단 TUI를 새 빌드로 교체했다. 헤더에는 `서브 조회 실패`가 표시됐다. 부모 범위 API가 `native_socket_unavailable`을 반환해 실제 서브 상태는 확인하지 못했다.
